# Клиент для децентрализованного мессенджера Backspace
## Библиотеки
Данный проект использует osu-framework и все его зависимости. Фреймворк не изменялся и на данный момент поставляется с официальной версией, неоптимизированной под данную задачу.
<br />
## Этап разработки
Этапы разработки можно увидеть в файле TODO.md. На данный момент мессенджер не является окончательной версией. Все стабильные версии публикуются в релизах.
На данный момент я не доходил до оптимизации движка.
